Ready for manual Nexus upload, replacing the earlier 1.0.5 bundle. Internal version: 1.0.6-test1. Automatic layout detection, regression and native host checks pass; startup, automatic map discovery and routes on both maps are confirmed by the game log and the user's visual check. This release removes the exact game-version/hash lock and includes the earlier resolution and tested vendor/NPC interaction fixes. Some resolutions may still need fixes. Combat and other interactions may briefly hide the route; it should return while the active navigation destination remains set. Minimap drift improvements are ongoing. Routing to user-placed map markers, pulse animation speed, pulse blur and route glow controls are planned for future updates.

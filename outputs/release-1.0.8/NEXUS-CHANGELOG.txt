Version 1.0.8 - November 10, 2026

- Fixed the game patch 2.04 failure where no route appeared and the panel showed "Reader stopped after an internal error."
- The road loader reads the road file by its actual size and accepts newer road format versions when every structural check passes. A format newer than the last tested one is reported as unverified in the panel.
- Automatic detection of the changed minimap object layout in patch 2.04, including the new destination icon type and the moved map visibility flags. A layout is used only when exactly one known layout matches.
- The full-map projection search covers a wider bounded window after patch 2.04 moved that data again.
- Route width, outline, pulse glow and player-to-road connector dashes now scale with display resolution: unchanged at 1920x1080, 2x at 3840x2160. The width setting means pixels at 1080p. Saved settings are kept, so routes draw thicker than before above 1920x1080 and thinner below it.
- Reader errors now show their reason in the panel.

Known issues: other resolutions/display layouts may still need fixes. Many DLC islands have no world-map roads, so routes there are expected to end at the nearest road point (not yet checked in game). Below 1080p with the Dotted style, a route width under about 1.5 can make the dots too small to draw. Combat and other interactions can temporarily hide the route; it should return while the active navigation destination remains set. Report cases that do not recover. Minimap drift/turn lag is still being tightened.

Upcoming, not included: routing to user-placed map markers, pulse animation speed, pulse blur and route glow controls.

Internal version: 1.0.8-test3. Tested on game patch 2.04 (executable 1.0.0.3576 / Steam build 26480954). Regression and native host checks pass. The production loader reads the untouched patch 2.04 road archive. The previous test build showed routes on the minimap and full-screen map, including full-map pan/zoom, at 1920x1080, and correct placement at 3840x2160. This build adds only the resolution-scaled width (unchanged at 1920x1080) and was run and approved at 3840x2160. Existing appearance settings are preserved.
